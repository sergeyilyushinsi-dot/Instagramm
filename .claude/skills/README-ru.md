# Скиллы /ig-* (instagram-agent-skill) — русская адаптация

Источник: https://github.com/Jakeschincariol/instagram-agent-skill, коммит `d03c56b`,
лицензия MIT (`LICENSE-instagram-agent-skill`). Автор — Jake Schincariol.

## Что изменено для русского языка

Все правки помечены в коде `# [ru]`.

- `hookscore.py`, `beats.py`, `swipe.py`, `caption.py`, `detect.py` — слова и имена собственные
  на кириллице, русские числительные и единицы (млн, руб, ₽, дней…), русские слова-маркеры
  ставок, слабые зачины («всем привет», «в этом видео»), обращения («ты/вы»), призывы
  («сохрани», «напиши в комментариях», «перешли»), хэштеги на кириллице.
- `humanize.py` — для русского текста **не трогает тире**: в русском это обычный знак,
  а не след генерации. Заглавная буква восстанавливается и для кириллицы.
- `detect.py` — для русского тире не штрафуется; проверка «голоса» не требует
  апострофов-сокращений, которых в русском нет.
- `ru_fix.py` (новый) — **автоправка без ручной работы**. Каждое правило либо сохраняет
  грамматику, либо не срабатывает:
  - вводные штампы в начале предложения удаляются («Не секрет, что многие…» → «Многие…»);
  - штампы внутри предложения заменяются конструкцией с тем же управлением
    («мне важно отметить, что» → «мне важно, что», «план на сегодняшний день» → «план на сегодня»);
  - канцелярит согласуется по падежу через pymorphy3: «является ключевым инструментом» →
    «— ключевой инструмент», «данного проекта» → «этого проекта», «в связи с ростом» →
    «из-за роста», «осуществляет» → «проводит», «с целью понять» → «, чтобы понять»;
  - дежурные призывы («Подписывайтесь…», «Ставь лайк, если…») удаляются целым предложением;
  - «данные» как существительное («данные клиентов», «по данным») не трогаются.
  Агент применяет это к подписи автоматически перед каждой публикацией (`igagent/textfix.py`).
- Регрессионные тесты: `python -m pytest tests` — 38 случаев: что меняется и что не должно.

## Где лежат файлы скиллов

Скиллы ссылаются на `~/.claude/instagram/` — в этом проекте вместо этого используется
`.claude/instagram/` в репозитории (голос, план, swipe-файл, лог), чтобы всё сохранялось в git.
