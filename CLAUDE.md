# Контент-агент Сергея (@ilyushin_s / Telegram «ЯEM»)

Python-бот `igagent` + скиллы `/ig-*`. Всё на русском.

## Каналы
- **Telegram «ЯEM»** — экспертные карусели с инфографикой и длинные тексты (публикует бот).
- **Instagram @ilyushin_s** — Reels и сторис; сторис анонсируют посты из Telegram.

## Где что лежит
- `config/profile.yaml` — профиль, голос, рубрики (главный источник правды); `config/settings.yaml` — расписание, тема слайдов.
- `content/queue/*.yaml` — карточки постов (`idea → draft → approved → published`). Публикуется только `approved`.
- `.claude/instagram/` — файлы скиллов: `voice.md`, `plan.md`, `swipe.md`, `log.md`.
  **Скиллы `/ig-*` пишут про `~/.claude/instagram/` — в этом проекте всегда используй `.claude/instagram/`.**
- `.claude/skills/ig-*` — скиллы (русская адаптация, см. `.claude/skills/README-ru.md`).

## Как работать с текстами
1. Пишешь пост или сценарий — следуй соответствующему скиллу: `/ig-reel` (Reels), `/ig-story` (сторис),
   `/ig-carousel` (правила копирайтинга для каруселей Telegram; картинки рендерит `igagent/slides.py`,
   не HTML), `/ig-caption` (подписи к Reels), `/ig-plan` (неделя для обоих каналов).
2. Перед сохранением прогоняй текст: `python -m igagent lint <id карточки>` — humanize + детектор + линтер подписи.
3. Никогда не выдумывай цифры, клиентов и факты — `[УТОЧНИТЬ: ...]` (агент такое не опубликует).
4. Коммерческие данные AM.TECH не раскрывать.

## Ограничения
- Ключа Claude API нет: планы и тексты пишутся в сессиях Claude Code, GitHub Actions публикует и собирает статистику.
- Instagram-публикация ждёт хранилища (S3/R2); стикеры, опросы и ссылки в сторис — только вручную.
